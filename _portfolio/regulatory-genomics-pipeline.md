**Stack:** Nextflow, ENCODE, HPC, Git, scientific Python  
**Context:** CBCRG · 2025 – Present

Developing reproducible data pipelines for TB-scale regulatory-genomics data on HPC infrastructure. The workflows automate ingestion, quality control, metadata harmonization, and experiment–control matching across heterogeneous ENCODE datasets.

**Key work:**
- Build validation and data-lineage checks that make results traceable across inputs, configurations, and downstream model artifacts
- Extract high-dimensional signal features from noisy sequencing tracks
- Detect and surface data-quality anomalies before training and downstream analysis

The goal is to make large biological datasets not only processable, but auditable: each downstream feature should be connected to its source data, transformation path, and quality checks.
