**Stack:** Python, Kubeflow, Google Cloud Storage, Parquet, knowledge graphs  
**Context:** GenBio AI · 2026 – Present

Curating and harmonizing heterogeneous biomedical interaction datasets for Interactome-FM, a foundation-model data resource that connects genes, drugs, pathways, regulatory interactions, protein complexes, and ligand–receptor relationships.

**Key work:**
- Standardize knowledge-graph metadata, edge schemas, file inventories, cloud paths, and provenance across sources
- Build and validate enriched graph artifacts with **132,498 nodes, 32.5 million edges, and 56 edge types**
- Manage reproducible integration workflows, GCS uploads, and technical documentation

The central engineering challenge is not simply graph size: it is maintaining biological meaning, source traceability, and consistent schemas while combining data produced under very different assumptions.
